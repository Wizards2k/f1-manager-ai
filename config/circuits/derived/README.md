# Circuit derived profiles

Purpose: store per-circuit configs already combined from global defaults + raw profiles (Pirelli/telemetry) + setup bounds. Loaded directly at runtime (no on-the-fly merge).

Structure:
- `config/circuits/derived/<circuit_id>/tyre_params.json`
- `config/circuits/derived/<circuit_id>/brake_params.json`
- `config/circuits/derived/<circuit_id>/pu_maps.json`
- `config/circuits/derived/<circuit_id>/damage_coeffs.json`

Generated by: `scripts/build_circuit_profiles.py`
Inputs:
- global defaults in `config/tyres|brakes|pu|damage/*_global_default.json`
- raw circuit data in `python_backend/data/circuits/` (Pirelli profiles, telemetry)
- setup bounds per circuito in `config/setup/setup_mapping_v2.json`

Regenerate whenever global defaults or raw circuit data change.
