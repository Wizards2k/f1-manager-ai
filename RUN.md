# Come avviare il simulatore F1 Manager AI

## Prerequisiti
- Python 3.8+ installato
- pip (Python package manager)

## Installazione dipendenze
```bash
pip install -r requirements.txt
```

## Avvio dell'applicazione
```bash
python app.py
```

## Accesso
Apri il browser e visita: http://localhost:5001

## Funzionalità implementate
- ✅ Circuit di Monza renderizzato con coordinate reali
- ✅ 20 auto (2 per team) con colori ufficiali F1 2025
- ✅ Numeri piloti visibili sui pallini
- ✅ Tempi sul giro realistici (~80 secondi)
- ✅ Layout split-screen (75% circuito, 25% tabella tempi)
- ✅ Aggiornamento real-time delle posizioni
- ✅ Tabella tempi dal vivo ordinata per performance
- ✅ Interfaccia dark theme professionale
